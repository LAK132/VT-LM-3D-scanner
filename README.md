# Vive Tracker/Leap Motion 3D scanner

## OpenVR
1. Install SteamVR (>v2.12.14)
2. Configure the null headset: https://github.com/username223/SteamVRNoHeadset

## Ultraleap
1. Install Ultraleap software for the Leap Motion: https://www.ultraleap.com/downloads/leap-controller/
2. Set `leapc_inc_path` and `leapc_lib_path` in `meson_options.txt` if using a non-standard install location
